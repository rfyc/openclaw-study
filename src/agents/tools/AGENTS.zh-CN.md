# 智能体工具性能

工具测试不应为静态工具描述加载完整的通道或插件运行时。

## 护栏规则

- 消息工具发现应通过共享发现辅助工具和轻量级通道产物流转，回退到完整通道插件加载之前。
- 通道特定的工具 schema、操作列表和静态能力应属于插件拥有的辅助工具，由完整插件和轻量级产物复用。
- 不要为 schema 或能力断言向智能体工具测试添加直接的捆绑插件导入。如果生产路径需要相同数据，改为推广一个小的公共产物。
- 如果单个断言开始付出多秒的导入/设置成本，将静态描述符路径从运行时执行中分离，而不是在宽泛导入周围添加更多 mock。

## 验证

- 对于 `src/agents/tools/*.test.ts` 性能工作，使用 `pnpm test <file>` 比较变更前后的目标文件运行时间。
- 添加或更改捆绑插件产物时运行 `pnpm build`。
