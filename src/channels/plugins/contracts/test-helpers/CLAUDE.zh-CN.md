# 通道契约辅助工具边界

此目录存放核心拥有的通道契约测试辅助工具。

本文件在 `src/channels/AGENTS.md` 的基础上添加通道特定规则。

## 捆绑插件导入

- 此目录中的核心契约辅助工具不得将硬编码的仓库相对导入写入 `extensions/**`。
- 当辅助工具需要捆绑插件的公共/测试层面时，通过 `src/test-utils/bundled-plugin-public-surface.ts` 处理。
- 优先使用 `loadBundledPluginTestApiSync(...)` 来急切访问导出的测试辅助工具。
- 当测试需要模块 id 用于动态导入或 mock 时，优先使用 `resolveRelativeBundledPluginPublicModuleId(...)`。
- 如果 `vi.mock(...)` 提升会过早求值模块 id，使用带解析模块 id 的 `vi.doMock(...)` 代替硬编码路径。
- 对于契约辅助工具，当契约只需要能力、会话绑定钩子、路由元数据或出站负载辅助工具时，优先使用最小化的内存通道/插件固件。不要为附带设置加载宽泛的 `api.ts`、`runtime-api.ts` 或 `test-api.ts` 桶文件。
- 如果捆绑插件解析器是被测契约，加载拥有该解析器的窄型模块或推广一个小型公共产物。避免仅为解析目标 id 而拉取完整的扩展桶文件。

## 意图

- 保持核心契约辅助工具与生产代码使用的相同公共/插件边界对齐。
- 避免核心契约辅助工具因方便而开始通过路径访问捆绑插件私有文件的漂移。
