# 出站测试性能

出站辅助工具位于热回复、操作、媒体和通道契约路径上。除非有意演练真实交付，否则保持参数和负载测试范围窄小。

## 护栏规则

- 对于发送参数、媒体来源、别名和负载形状覆盖，优先使用纯参数/规范/规范化辅助工具。不要在测试仅断言规范化参数时导入真实交付运行时。
- 避免在宽泛的出站交付模块周围使用带 `importActual()` 的局部真实 mock。mock 被测试的精确接缝，然后在专注的集成测试中覆盖真实交付运行时。
- 在发现插件拥有的媒体/操作元数据之前，首先检查调用是否实际包含插件拥有的参数。标准发送参数不应触发捆绑通道消息工具发现。

## 验证

- 使用 `pnpm test <file>` 对受影响的出站测试文件进行变更前后的基准测试。
- 更改共享出站辅助工具时运行最近的媒体/操作/负载契约测试。
