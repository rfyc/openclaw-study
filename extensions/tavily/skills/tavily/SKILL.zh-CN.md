# Tavily 工具

## 何时使用哪个工具

| 需求             | 工具             | 使用时机                                     |
| ---------------- | ---------------- | -------------------------------------------- |
| 快速网络搜索     | `web_search`     | 基础查询，无需特殊选项                       |
| 带高级选项的搜索 | `tavily_search`  | 需要深度、主题、域名过滤、时间范围或 AI 答案 |
| 从 URL 提取内容  | `tavily_extract` | 有具体 URL，需要其内容                       |

## web_search

当选择 Tavily 作为搜索 provider 时自动启用。用于不需要 Tavily 特定选项的直接查询。

| 参数    | 描述             |
| ------- | ---------------- |
| `query` | 搜索查询字符串   |
| `count` | 结果数量（1-20） |

## tavily_search

需要对搜索行为进行精细控制时使用。

| 参数              | 描述                                                   |
| ----------------- | ------------------------------------------------------ |
| `query`           | 搜索查询字符串（保持在 400 字符以内）                  |
| `search_depth`    | `basic`（默认，均衡）或 `advanced`（最高相关性，较慢） |
| `topic`           | `general`（默认）、`news`（实时更新）或 `finance`      |
| `max_results`     | 结果数量，1-20（默认：5）                              |
| `include_answer`  | 包含 AI 生成的答案摘要（默认：false）                  |
| `time_range`      | 按时效性过滤：`day`、`week`、`month` 或 `year`         |
| `include_domains` | 限制结果的域名数组                                     |
| `exclude_domains` | 从结果中排除的域名数组                                 |

### 搜索深度

| 深度       | 速度 | 相关性 | 最适合                       |
| ---------- | ---- | ------ | ---------------------------- |
| `basic`    | 较快 | 高     | 通用查询（默认）             |
| `advanced` | 较慢 | 最高   | 精确查找、特定事实、详细研究 |

### 使用技巧

- **将查询保持在 400 字符以内** — 想着搜索词，而不是提示。
- **将复杂查询拆分为子查询**以获得更好的结果。
- **使用 `include_domains`**专注于可信来源。
- **使用 `time_range`**获取最新信息（新闻、当前事件）。
- **使用 `include_answer`**当你需要快速综合答案时。

## tavily_extract

当你有具体 URL 并需要其内容时使用。处理 JavaScript 渲染的页面并返回干净的 markdown。支持面向查询的分块提取。

| 参数                | 描述                                                         |
| ------------------- | ------------------------------------------------------------ |
| `urls`              | 要提取的 URL 数组（每次请求 1-20 个）                        |
| `query`             | 按与此查询的相关性重新排列提取的分块                         |
| `extract_depth`     | `basic`（默认，快速）或 `advanced`（用于 JS 密集页面、表格） |
| `chunks_per_source` | 每个 URL 的分块数，1-5（需要 `query`）                       |
| `include_images`    | 在结果中包含图片 URL（默认：false）                          |

### 提取深度

| 深度       | 使用时机                                |
| ---------- | --------------------------------------- |
| `basic`    | 简单页面——先试这个                      |
| `advanced` | JS 渲染的 SPA、动态内容、表格、嵌入内容 |

### 使用技巧

- **每次请求最多 20 个 URL** — 将更大的列表批量分成多次调用。
- **使用 `query` + `chunks_per_source`**只获取相关内容，而不是完整页面。
- **先试 `basic`**，如果内容缺失或不完整则回退到 `advanced`。
- 如果 `tavily_search` 结果已经包含你需要的片段，跳过提取步骤。

## 选择正确的工作流

遵循这个升级模式——从简单开始，只在必要时升级：

1. **`web_search`** — 快速查找，不需要特殊选项。
2. **`tavily_search`** — 需要深度控制、主题过滤、域名过滤、时间范围或 AI 答案。
3. **`tavily_extract`** — 有具体 URL，需要其完整内容或有针对性的分块。

当你需要先找页面，然后获取其完整内容时，结合使用搜索 + 提取。
