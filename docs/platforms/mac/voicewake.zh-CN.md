# 语音唤醒与一键通话

## 模式

- **唤醒词模式**（默认）：始终运行的语音识别器等待触发词（`swabbleTriggerWords`）。匹配时开始捕获，显示带有部分文本的叠加层，并在静默后自动发送。
- **一键通话（按住右 Option 键）**：按住右 Option 键立即开始捕获——不需要触发词。按住期间叠加层出现；释放后经过短暂延迟完成并转发，以便你可以调整文本。

## 运行时行为（唤醒词）

- 语音识别器存在于 `VoiceWakeRuntime` 中。
- 触发仅在唤醒词和下一个词之间有**有意义的停顿**（约 0.55 秒间隔）时触发。即使在命令开始之前，叠加层/铃声也可以在停顿时开始。
- 静默窗口：语音流动时 2.0 秒，只听到触发词时 5.0 秒。
- 硬停止：120 秒以防止失控会话。
- 会话之间的防抖：350ms。
- 叠加层通过带有提交/易变着色的 `VoiceWakeOverlayController` 驱动。
- 发送后，识别器干净地重启以监听下一个触发词。

## 生命周期不变量

- 如果语音唤醒已启用且权限已授予，唤醒词识别器应该处于监听状态（明确的一键通话捕获期间除外）。
- 叠加层可见性（包括通过 X 按钮手动关闭）不得阻止识别器恢复。

## 粘性叠加层失败模式（以前）

以前，如果叠加层卡住可见并且手动关闭它，语音唤醒可能显示"死了"，因为运行时的重启尝试可能被叠加层可见性阻止，且没有安排后续重启。

加固措施：

- 唤醒运行时重启不再被叠加层可见性阻止。
- 叠加层关闭完成通过 `VoiceSessionCoordinator` 触发 `VoiceWakeRuntime.refresh(...)`，因此手动 X 关闭始终恢复监听。

## 一键通话细节

- 快捷键检测使用**右 Option**（`keyCode 61` + `.option`）的全局 `.flagsChanged` 监听器。我们只观察事件（不吞噬）。
- 捕获管道在 `VoicePushToTalk` 中：立即开始语音，将部分文本流式传输到叠加层，并在释放时调用 `VoiceWakeForwarder`。
- 一键通话开始时，我们暂停唤醒词运行时以避免双重音频捕获；释放后自动重启。
- 权限：需要麦克风 + 语音；看到事件需要辅助功能/输入监控批准。
- 外接键盘：某些键盘可能无法按预期暴露右 Option——如果用户报告遗漏，提供备用快捷键。

## 用户设置

- **语音唤醒**切换：启用唤醒词运行时。
- **按住 Cmd+Fn 说话**：启用一键通话监听器。在 macOS < 26 上禁用。
- 语言和麦克风选择器，实时电平表，触发词表，测试器（仅本地；不转发）。
- 麦克风选择器在设备断开时保留上次选择，显示断开提示，并临时回退到系统默认值直到返回。
- **声音**：触发检测和发送时的铃声；默认使用 macOS "Glass" 系统声音。你可以为每个事件选择任何 `NSSound` 可加载的文件（例如 MP3/WAV/AIFF）或选择**无声音**。

## 转发行为

- 启用语音唤醒时，转录文本被转发到活跃的网关/智能体（与 Mac 应用其他部分使用相同的本地/远程模式）。
- 回复被传递到**最后使用的主提供商**（WhatsApp/Telegram/Discord/WebChat）。如果传递失败，错误被记录，运行仍然可以通过 WebChat/会话日志查看。

## 转发载荷

- `VoiceWakeForwarder.prefixedTranscript(_:)` 在发送前预置机器提示。在唤醒词和一键通话路径之间共享。

## 快速验证

- 开启一键通话，按住 Cmd+Fn，说话，释放：叠加层应显示部分文本然后发送。
- 按住期间，菜单栏耳朵应保持放大（使用 `triggerVoiceEars(ttl:nil)`）；释放后下降。
