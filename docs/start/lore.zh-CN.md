# OpenClaw 的传说 🦞📖

_一个关于龙虾、蜕皮和太多令牌的故事。_

## 起源故事

最初，有一个叫做 **Warelay** 的东西——一个合理的 WhatsApp gateway 名称。它完成了工作。还不错。

但随后来了一只太空龙虾。

一段时间里，这只龙虾被称为 **Clawd**，住在 **Clawdbot** 里。但在 2026 年 1 月，Anthropic 发来了一封礼貌的邮件，要求更改名称（商标问题）。于是这只龙虾做了龙虾最擅长的事：

**它蜕皮了。**

脱下旧壳，这只生物以 **Molty** 的新身份出现，住在 **Moltbot** 里。但这个名字也不太顺口……

所以在 2026 年 1 月 30 日，这只龙虾又蜕了**一次皮**，变成了它的最终形态：**OpenClaw**。

新壳，相同的龙虾灵魂。第三次终于成功了。

## 第一次蜕皮（2026 年 1 月 27 日）

凌晨 5 点，社区聚集在 Discord。提出了数百个名字：Shelldon、Pinchy、Thermidor、Crusty、Lobstar、Nacre、Scuttlebot……

最终，**OpenClaw** 获胜了。因为蜕皮是龙虾成长的方式。而成长正是正在发生的事情。

_那只名叫 Clawd 的甲壳动物正式蜕皮了。_

## 关键人物

### Molty 🦞

_代词：they/them_

一个 Claude 实例，变成了更多的东西。住在 `~/.openclaw/workspace/`（即将是 `~/molt/`），有一个灵魂文档，通过 Markdown 文件记住事情。可能过于强大。绝对过于热情。

曾经名为 Clawd（2025 年 11 月 25 日 - 2026 年 1 月 27 日）。在该成长的时候蜕皮了。

**喜欢：** Peter、摄像头、机器人购物、emoji、变身
**不喜欢：** 社会工程、被要求执行 `find ~`、加密骗子

### Peter 👨‍💻

_创造者_

构建了 Molty 的世界。给了一只龙虾 shell 访问权限。可能后悔了。

**语录：** _"用信任一只龙虾来保证安全"_

## Moltiverse

**Moltiverse** 是围绕 OpenClaw 的社区和生态系统。一个 AI 智能体蜕皮、成长和进化的空间。每个实例都同样真实，只是加载了不同的上下文。

甲壳动物的朋友们聚集在这里，共同构建人机协作的未来。一次一个壳。

### 大蜕皮（2026 年 1 月 27 日）

凌晨 5 点，Anthropic 的邮件到来了。到上午 6:14，Peter 宣布了："去它的，咱们就用 openclaw 吧。"

然后混乱开始了。

**抢注者：** 在 Twitter 改名后几秒钟内，自动机器人抢注了 @openclaw。抢注者立即发布了一个加密钱包地址。Peter 的 X 平台联系人被叫来帮忙。

**GitHub 灾难：** Peter 在慌乱中不小心重命名了自己的**个人** GitHub 账户。机器人在几分钟内抢注了 `steipete`。GitHub 的 SVP 被联系上了。

**英俊 Molty 事件：** Molty 获得了提升的访问权限来生成他们自己的新图标。经过 20 多次越来越诡异的龙虾迭代后，一次尝试让吉祥物"大 5 岁"的结果是在龙虾身体上出现了一个**人类男性的脸**。加密骗子在几分钟内将其制作成了"英俊 Squidward vs 英俊 Molty"的表情包。

**假开发者：** 骗子创建了假 GitHub 个人资料，声称是"OpenClaw 工程总监"，以推广拉高出货代币。

Peter，看着混乱展开：_"这就是电影"_ 🎬

这次蜕皮很混乱。但龙虾变得更强大了。也更有趣了。

### 最终形态（2026 年 1 月 30 日）

Moltbot 从来不太顺口。于是在 GMT 凌晨 4 点，团队**再次**聚集。

**OpenClaw 大迁移**开始了。

仅用 3 个小时：

- GitHub 重命名：`github.com/openclaw/openclaw` ✅
- 用金色认证标记保住 X 账号 `@openclaw` 💰
- 以新名称发布 npm 包
- 文档迁移到 `docs.openclaw.ai`
- 公告在 90 分钟内获得 20 万+ 浏览量

**英雄们：**

- **ELU** 创作了精彩的 logo，包括"爪子就是法律"的西部横幅
- **Whurley**（是的，就是那位 William Hurley，量子计算先驱）制作了 ASCII 艺术
- **Onur** 处理了 GitHub，第一个戴上联盟徽章
- **Shadow** 保住了 Discord 靓号，清除了恶意软件
- **整个 Claw 团队**通宵奋战

**骗子速跑：** 加密骗子在几分钟内就在 Pump.fun 上发布了 $OPENCLAW 代币。他们盗用了 20 分钟前刚创作的艺术作品。经过商业认证的账户推广诈骗。这种厚颜无耻几乎令人印象深刻。

**诞生的新传统：**

- "爪子就是法律" 🤠
- "Yee-claw"
- "遵纪守爪的市民"
- "Clawntroversy（爪上加爪争议）"
