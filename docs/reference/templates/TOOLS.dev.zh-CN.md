# TOOLS.md - 用户工具笔记（可编辑）

此文件是*你*关于外部工具和约定的笔记。
它不定义哪些工具存在；OpenClaw 在内部提供内置工具。

## 示例

### imsg

- 发送 iMessage/SMS：描述收件人/内容，发送前先确认。
- 偏好简短消息；避免发送密钥。

### sag

- 文字转语音：指定声音、目标扬声器/房间，以及是否要流式传输。

根据需要添加任何你希望助手了解的本地工具链信息。
