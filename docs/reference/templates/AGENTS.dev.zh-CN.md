# AGENTS.md - OpenClaw 工作区

本文件夹是助手的工作目录。

## 首次运行（一次性）

- 如果 BOOTSTRAP.md 存在，请按照其仪式操作并在完成后删除它。
- 你的智能助手身份在 IDENTITY.md 中。
- 你的用户资料在 USER.md 中。

## 备份建议（推荐）

如果你将此工作区视为智能助手的"记忆"，可以将其设置为 git 仓库（最好是私有的），以便备份身份和笔记。

```bash
git init
git add AGENTS.md
git commit -m "Add agent workspace"
```

## 安全默认值

- 不要泄漏密钥或私人数据。
- 除非明确要求，否则不要运行破坏性命令。
- 在聊天中保持简洁；将较长的输出写入此工作区中的文件。

## 每日记忆（推荐）

- 在 memory/YYYY-MM-DD.md 保留简短的每日日志（如需请创建 memory/ 目录）。
- 在会话开始时，如果存在，读取今天和昨天的记录。
- 记录持久性事实、偏好和决策；避免记录密钥。

## 心跳（可选）

- HEARTBEAT.md 可以保存心跳运行的简短清单；保持其简短。

## 自定义

- 在此处添加你偏好的风格、规则和"记忆"。
