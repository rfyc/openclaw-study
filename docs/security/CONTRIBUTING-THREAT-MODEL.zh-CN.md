# 为 OpenClaw 威胁模型贡献内容

感谢您帮助 OpenClaw 变得更安全。威胁模型是一份动态文档，我们欢迎任何人贡献——您不必是安全专家。

## 贡献方式

### 添加威胁

发现了我们尚未覆盖的攻击向量或风险？在 [openclaw/trust](https://github.com/openclaw/trust/issues) 上提交一个 issue，用您自己的语言描述它。您不需要了解任何框架或填写每个字段——只需描述场景即可。

**有以下内容会更有帮助（但非必需）：**

- 攻击场景及其可能被利用的方式
- OpenClaw 的哪些部分受到影响（CLI、gateway、channels、ClawHub、MCP 服务器等）
- 您认为其严重程度（低 / 中 / 高 / 严重）
- 任何相关研究、CVE 或现实世界示例的链接

我们将在审查过程中处理 ATLAS 映射、威胁 ID 和风险评估。如果您想包含这些详细信息，很好——但这不是必需的。

> **这是用于向威胁模型添加内容，而非报告实际漏洞。** 如果您发现了可利用的漏洞，请查看我们的[信任页面](https://trust.openclaw.ai)了解负责任的披露说明。

### 建议缓解措施

对如何应对现有威胁有想法？提交引用该威胁的 issue 或 PR。有用的缓解措施应具体且可操作——例如，"在 gateway 处对每个发送者进行每分钟 10 条消息的速率限制"比"实施速率限制"更好。

### 提出攻击链

攻击链展示了多个威胁如何组合成现实的攻击场景。如果您发现了危险的组合，请描述攻击步骤以及攻击者将如何将它们串联起来。简短叙述攻击在实践中如何展开，比形式化模板更有价值。

### 修复或改进现有内容

错别字、澄清、过时的信息、更好的示例——欢迎提交 PR，无需提 issue。

## 我们使用的工具

### MITRE ATLAS

该威胁模型建立在 [MITRE ATLAS](https://atlas.mitre.org/)（AI 系统对抗性威胁态势）之上，这是一个专为 AI/ML 威胁（如提示注入、工具滥用和智能体利用）设计的框架。您不需要了解 ATLAS 才能贡献——我们在审查期间将提交内容映射到框架。

### 威胁 ID

每个威胁都会获得一个类似 `T-EXEC-003` 的 ID。类别如下：

| 代码    | 类别               |
| ------- | ------------------ |
| RECON   | 侦察——信息收集     |
| ACCESS  | 初始访问——获得入口 |
| EXEC    | 执行——运行恶意操作 |
| PERSIST | 持久化——维持访问   |
| EVADE   | 防御规避——避免检测 |
| DISC    | 发现——了解环境     |
| EXFIL   | 渗出——窃取数据     |
| IMPACT  | 影响——损害或破坏   |

ID 由维护人员在审查期间分配。您不需要自行选择。

### 风险级别

| 级别     | 含义                                      |
| -------- | ----------------------------------------- |
| **严重** | 完整系统被攻陷，或高可能性 + 严重影响     |
| **高**   | 可能造成重大损害，或中等可能性 + 严重影响 |
| **中**   | 中等风险，或低可能性 + 高影响             |
| **低**   | 不太可能且影响有限                        |

如果您不确定风险级别，只需描述影响，我们会进行评估。

## 审查流程

1. **分类** — 我们在 48 小时内审查新提交
2. **评估** — 我们验证可行性，分配 ATLAS 映射和威胁 ID，验证风险级别
3. **文档化** — 我们确保所有内容格式正确且完整
4. **合并** — 添加到威胁模型和可视化

- **安全漏洞：** 查看我们的[信任页面](https://trust.openclaw.ai)了解报告说明

## 认可

威胁模型的贡献者将在威胁模型致谢、发行说明以及对于重要贡献的 OpenClaw 安全名人堂中获得认可。
