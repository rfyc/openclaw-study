# xAI 插件

为 OpenClaw 添加 xAI 模型提供商支持。

## 发行版本

- 软件包：`@openclaw/xai-plugin`
- 安装方式：包含在 OpenClaw 中

## 界面

提供商：xai；合约：imageGenerationProviders、mediaUnderstandingProviders、realtimeTranscriptionProviders、speechProviders、tools、videoGenerationProviders、webSearchProviders
