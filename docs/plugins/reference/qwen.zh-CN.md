# Qwen 插件

为 OpenClaw 添加 Qwen、Qwen Cloud、Model Studio、DashScope 模型提供商支持。

## 发行版本

- 软件包：`@openclaw/qwen-provider`
- 安装方式：包含在 OpenClaw 中

## 界面

提供商：qwen、qwencloud、modelstudio、dashscope；合约：mediaUnderstandingProviders、videoGenerationProviders
