# OpenClaw Android UI 风格指南

范围：`apps/android` 中的所有原生 Android UI（Jetpack Compose）。
目标：在引导、设置和未来屏幕中构建一个统一的视觉系统。

## 1. 设计方向

- 干净、低调的界面。
- 首先保证强可读性。
- 每个屏幕状态只有一个清晰的主要操作。
- 高级控件的渐进式披露。
- 确定性流程：早期验证，清晰失败。

## 2. 风格基准

引导流程定义了当前的视觉基准。
新屏幕应与该语言匹配，除非有强烈的产品理由不这样做。

基准特征：

- 具有微妙深度的浅中性背景。
- 活跃/主要状态的清晰蓝色强调色。
- 用于结构的强边框层次。
- 中等/半粗体排版（无细体文字）。
- 分隔线和间距布局，而非重型卡片嵌套。

## 3. 核心设计标记

将这些作为新 Compose UI 的共享设计标记使用。

- 背景渐变：`#FFFFFF`、`#F7F8FA`、`#EFF1F5`
- 界面：`#F6F7FA`
- 边框：`#E5E7EC`
- 强边框：`#D6DAE2`
- 主要文字：`#17181C`
- 次要文字：`#4D5563`
- 第三文字：`#8A92A2`
- 主要强调色：`#1D5DD8`
- 柔和强调色：`#ECF3FF`
- 成功：`#2F8C5A`
- 警告：`#C8841A`

规则：当现有标记适用时，不要引入随机的每屏幕颜色。

## 4. 排版

主要字体系列：Manrope（`400/500/600/700`）。

推荐比例：

- 显示：`34sp / 40sp`，粗体
- 节标题：`24sp / 30sp`，半粗体
- 标题/操作：`16sp / 22sp`，半粗体
- 正文：`15sp / 22sp`，中等
- 标注/辅助：`14sp / 20sp`，中等
- 说明 1：`12sp / 16sp`，中等
- 说明 2：`11sp / 14sp`，中等

仅对命令、设置码、端点类值使用等宽字体。
硬性规则：避免在浅色背景上使用超细字重。

## 5. 布局与间距

- 遵守安全绘图区域插入。
- 主要通过间距 + 分隔线保持内容层次。
- 优先使用 `8/10/12/14/20dp` 的垂直节奏。
- 对多步骤或高重要性流程使用固定底部操作。
- 避免不必要的容器嵌套。

## 6. 按钮与操作

- 主要操作：填充强调色按钮，视觉上占主导地位。
- 次要操作：较低强调（描边/文字/界面按钮）。
- 仅图标按钮必须保持清晰且目标尺寸 >=44dp。
- 操作行中的返回按钮默认使用圆角方形，而非圆形。

## 7. 输入与表单

- 始终显示明确的标签或清晰的上下文标题。
- 保持辅助文字简短且可操作。
- 在前进步骤前进行验证。
- 优先使用即时内联错误，而非隐藏的失败状态。
- 明确保留可选的高级字段（`Manual`、`Advanced` 等）。

## 8. 进度与多步骤流程

- 使用清晰的步骤计数（`第 X 步，共 N 步`）。
- 当步骤是离散的时，使用带标签的进度轨道/指示器。
- 保持导航可预测：前进/后退行为不应让用户感到意外。

## 9. 无障碍

- 最小实际触摸目标：`44dp`。
- 不要仅依靠颜色来表示状态。
- 保持所有文字层级的高对比度。
- 为仅图标控件添加有意义的 `contentDescription`。

## 10. 架构规则

- `MainViewModel` 中的持久 UI 状态。
- Composable：状态输入，回调输出。
- Composable 中没有业务/网络逻辑。
- 明确保留副作用（`LaunchedEffect`、activity result API）。

## 11. 真实来源

- `app/src/main/java/ai/openclaw/android/ui/OpenClawTheme.kt`
- `app/src/main/java/ai/openclaw/android/ui/OnboardingFlow.kt`
- `app/src/main/java/ai/openclaw/android/ui/RootScreen.kt`
- `app/src/main/java/ai/openclaw/android/ui/SettingsSheet.kt`
- `app/src/main/java/ai/openclaw/android/MainViewModel.kt`

如果风格和实现出现分歧，在同一次变更中同时更新两者。
